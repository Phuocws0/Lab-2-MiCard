# Lab 2: MiCard - How to Build Beautiful UIs with Flutter Widgets

A TypeScript React Native version of the original MiCard profile app. It keeps the supplied avatar, name, software engineering title, phone number, and email, with cleaner spacing and contact cards.

## Run on Android

```sh
cd source
npm install
npm run android
```

Requirements: Node.js 22.11 or newer, Java, Android Studio/SDK, and an Android emulator or device. Build a release APK with `cd source/android && ./gradlew assembleRelease`.

The release app was launched and visually checked on the Pixel 7 Android emulator. The local demo video is stored separately from this repository.
